# 极速云专线 - Telegram 机器人专属注册与群组鉴权使用指南 (开源分享版)

> **说明**：本手册为开源标准指南，涉及 Token、管理员 ID 等敏感数据均已替换为假数据示例，适合分享与团队协作。

---

## 📌 一、功能特性概述

1. **零第三方依赖**：纯 Node.js 内置模块驱动，适配极小内存 VPS（256MB+）及 Alpine 容器；
2. **专属群成员验证**：集成 Telegram Bot API 实时判断用户是否属于指定群组；
3. **一人一号防刷锁**：每个 Telegram 账号严格限制仅能注册一个节点账号；
4. **全自动订阅下发**：注册成功即刻生成多协议通用订阅与 Clash/Mihomo 订阅；
5. **智能自愈长轮询**：高可用 Long-Polling 引擎，网络抖动或超时自动平滑重连。

## ⚙️ 二、环境变量配置 (.env 示例)

```ini
# 【选填项】Telegram 机器人 Bot Token (通过 @BotFather 获取)
TG_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ

# 【选填项】站长/管理员 Telegram 数字 ID (用于接收注册通知与执行管理指令)
TG_ADMIN_ID=123456789

# 【选填项】允许注册的限定群组 (例如: @s5gydl)
TG_REQUIRED_GROUP=@s5gydl

# 【选填项】Telegram API 官方或反向代理地址 (国内机器可配置自建 Worker 反代)
TG_API_BASE=https://api.telegram.org

# 【选填项】是否开放网页端自主注册 (默认 false，仅允许 Telegram 机器人开通)
DEFAULT_ALLOW_REGISTER=false
```

## 🤖 三、机器人交互指令列表

### 1. 用户端功能

- `/start`：唤醒机器人并查看欢迎引导与加群链接；
- `/reg <账号> [密码]`：注册专属节点账号（系统自动进行群成员核验与单账号排重）；
- `/my`：查询绑定的账号信息、剩余流量、到期时间与节点订阅链接；
- `/help`：查看所有指令帮助。

### 2. 站长管理功能 (仅限配置的 TG_ADMIN_ID)

- `/status`：查看服务器在线 IP、总用户数与内存状态；
- `/unbind <用户名或TG_ID>`：解绑某个用户的 Telegram 绑定，允许重新注册；
- `/deluser <用户名>`：从系统数据库中彻底删除用户；
- `/broadcast <通知内容>`：向所有绑定 Telegram 的用户群发广播。

## 📋 四、管理员部署注意事项

1. **机器人加群**：请务必将您的 Telegram Bot 邀请进限定的目标群组（例如 `@s5gydl`），并赋予管理员身份或查看群成员权限；
2. **私聊注册保护**：若用户在公开群聊内发送包含密码的注册指令，系统会自动拦截并提醒用户转入私聊，确保密码安全。
