# VPS-Backtrack 踩坑与复利沉淀日志 (Error Report)

## 问题一：从 Argo 隧道切换到端口回溯 (Origin Rules) 的架构适配
*   **现象**：NAT 机器无 80/443 独立公网端口，若不用 Argo 隧道，Cloudflare 默认小黄云回源只认固定非标端口。
*   **原因**：NAT 服务商随机分配的端口通常不在 Cloudflare 免费端口列表内。
*   **解决方案**：采用 Cloudflare Origin Rules（源服务器规则），在规则中指定将客户端发送到 443 优选 IP 的请求，在边缘重写目标端口为 NAT 机器的外部公网端口 `PUBLIC_PORT`，彻底省去了在 VPS 上下载和守护 `cloudflared` 二进制的巨大资源开销。

## 问题二：一键脚本在重复部署时的配置破坏
*   **现象**：用户重新拉取部署时，若直接覆盖 `.env` 会丢失已配置的密码和域名。
*   **原因**：未作已有环境变量感知。
*   **解决方案**：在 `setup.sh` 部署引导前优先解析目标目录已有的 `.env`，若发现已配置某项参数，提示框格式化展示 `[当前已配置: xxxx, 回车保持不变]`，直接回车即可平滑保留历史配置。
