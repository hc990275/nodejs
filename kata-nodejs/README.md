## Ⅱ. 核心功能与亮点

### 1. 毫秒级定向连接控制（零闪断保全）
- **0 秒定向掐断**：管理员在后台点击「封禁」或「删除」某个用户时，系统直接从内存句柄池定向销毁该用户的 TCP/WebSocket 连接，客户端即刻断流，后续握手 403 拒绝。
- **0 秒即时连通**：新增用户或前台自主注册后，无需重启服务或重载配置，下一毫秒即可连通。
- **全局零影响**：每个用户连接完全独立隔离，增删改查任何用户对其他在线用户**绝对 0 影响、0 丢包、0 闪断**。

### 2. 微测网 (Wetest.vip) 三网优选分发矩阵
- **彻底剔除 AWS**：专为国内网络环境优化，仅保留 **中国电信 (CT)、中国联通 (CU)、中国移动 (CM)** 以及 **CF 官方 Anycast** 四大线路。
- **智能测速与机房感知**：自动抓取实时 RTT 延迟与机场机房三字码（如 `FRA`、`SJC`、`HKG` 等），在订阅节点名称中精准标记。
- **独立开关控制**：后台提供 4 组独立开关与首选自定义 IP 覆盖输入框。

### 3. 微测网专业风格前台主页 (`/`)
- 对标微测网 (Wetest.vip) 专业测速大屏，清晰呈现电信、联通、移动落地优选节点数据。
- 登录后呈现用户个人已用流量、剩余有效期进度条，以及专属订阅链接的一键复制。
- 遵循后台「开放注册」开关，随时切换开放与关闭。

### 4. Element UI 现代扁平管理控制台 (`/admin`)
- **后台密码热修改与回写**：直接在界面修改管理员密码，保存后**自动原子回写至根目录 `.env`**，免进翼龙面板或重启容器。
- **注册与套餐运营控制**：一键开启/关闭前台自主注册，自定义新用户体验天数与流量额度。
- **用户全生命周期风控**：支持一键复制 UUID、重置流量、增加天数、修改限额、封禁/解封、永久删除。
- **308MB 容器探针**：实时展示真实常驻内存 (RSS)、活跃长连接数、持续运行时长。
